# moon-keeper

ポルノグラフィティで一番好きな楽曲は「月飼い」です。

> 月を飼うのと真夜中に水槽持ち出して窓辺においた、
> いとも簡単に捕獲された小ぶりな月が水面に浮かぶ

水面に浮かぶ小ぶりな月を、触って飼う。

## 触りかた

| 操作 | 起きること |
|---|---|
| なぞる | 波紋が広がる。速く払えば大きく崩れ、そっと触ればさざなみが立つ |
| 連打 | 波が積み上がる。消えたりはしない |
| 押しっぱなし | 水が凹み続け、離すと跳ね返る |
| 画面端のタブ「設え」 | 操作パネルが出る。3秒放っておくと自分で引っ込む |
| `Esc` | パネルを閉じる |

波紋は**画面の四辺で跳ね返る**。器は描いていない。見ている端末そのものが水槽。

水面を触っている間はタブが引っ込む。「水面を静める」はパネルの「水」の中。
月は掴んで動かせない——**空の月が水面に映っているもの**なので、
物として掬えると関係が壊れる。位置を変えたい時はパネルの「位置」から。

## 設えられるもの

パネルの最上段にプリセット（`真夜中` / `琥珀の月` / `蒼い月` / `血の月` /
`窓辺の朝` / `嵐`）。その下に個別の項目。

- **月** — 月明かりの色、明るさ、大きさ、深さ、水中の散乱、月縁のハロー、地球照、位置、漂い、傾き、月相
- **星** — 星の色、数、明るさ、瞬き、天の川、流れ星
- **水** — 波頭の色、うねり、波の残り、波紋の強さ、輪の太さ、輪の光、歪み、反射、
  月の透過、光の集束、光の合成、水面を静める
- **空と時計** — 夜空の色、窓辺の光、フィルターの色と強さ、時計の表示・秒・月の和名・濃さ
- **場所と品質** — 現在地の使用、描画品質

月明かりの色は月本体・水中の散乱・月縁のハロー・水面の透過・波頭にまとめて伝播する。

**光の合成**は波紋の光の乗せ方。加算は明るい所で 1.0 を超えて白飛びし、
隣り合う輪がつながって一枚の光の円に見えてしまう。スクリーンは 1.0 に漸近するので
輪の構造が残る（既定）。**フィルター**は最終段のオーバーレイ合成で、
月や波頭という明るい下地の色を深める（暗部はほとんど動かない）。

設定は自動で保存される。「この月のURLをコピー」で今の設えを人に渡せる
（`#s=...` に載る。ハッシュ付きで開くと保存済みの設定より優先される）。

`#panel=open` を付けて開くと、パネルが開いたまま固定される（調整用）。

## 月相

その時刻・その場所の**本物の月相**を計算して欠けを描いている。
Meeus『Astronomical Algorithms』の短縮版で、外部ライブラリは使っていない。
期待精度は照明率が ±0.5%、角度が ±1° 程度。

**照明率（欠け具合）は世界中どこで見ても同じ**で、緯度経度が効くのは
「欠けの傾き」だけ。だから位置情報は初回に要求せず、パネルで
「現在地を使う」を押した時にだけ確認する。押さなければタイムゾーンから概算する
（経度は UTC オフセットから、緯度は主要タイムゾーンの表から）。

月相はパネルで手動に切り替えて好きな満ち欠けにもできる。その場合も
欠けの傾きは実際の空のものを使う。

検証は `node tools/check-astro.mjs`。既知の朔望14件に対して照明率を照合する。

## 時計

水中に置いた極細の明朝体の数字。水面の屈折で歪んで揺れる。
波が立っている間は少し薄くなる。日付と月の和名（「十三夜」など）も併記できる。

## 構成

ビルドステップなし。素の ES モジュールと importmap だけで動くので、
静的ホスティングにそのまま置ける。`npm install` も不要。

```
index.html            シェル（DOM・CSS・importmap）
src/main.js           起動とレンダーループ
src/state.js          全パラメータ / 保存 / URL共有 / プリセット
src/perf.js           端末階層と適応品質
src/viewport.js       ビューポート実寸（iOS の URL バー対策）
src/input.js          Pointer Events
src/astro/            月相と観測地の推定
src/scene/            water / moon / stars / clock / dust
src/shaders/          GLSL
src/ui/panel.js       操作パネル
tools/                検証用スクリプト（依存ゼロ）
```

水面は ping-pong する2枚のレンダーターゲットの上で GPU が高さ場を解いている。
更新パスで勾配も書き出しておくので、水面シェーダは1フェッチで高さと法線の
両方を得られる。常時のうねりは低周波を頂点シェーダ、高周波をフラグメントに分けている。

性能は端末階層（低/中/高）で切り替わる。いちばん効くレバーは `pixelRatio` の上限で、
シミュレーション解像度・分割数・さざなみのオクターブ数・コースティクス・
天の川・水中の塵・月テクスチャの解像度が階層ごとに変わる。
起動時に静的に見積もり、そのあとは実測フレーム時間で上下する（パネルで固定も可能）。

## 開発

```sh
npx http-server -p 8080 -c-1 .

# 月相の検証（依存ゼロ）
node tools/check-astro.mjs

# スクリーンショットと性能計測（グローバルの playwright を使う）
NODE_PATH=$(npm root -g) node tools/shot.mjs
NODE_PATH=$(npm root -g) node tools/shot.mjs --perf --baseline=<比較対象のURL>

# 中・低階層用の軽い月テクスチャを作り直す
NODE_PATH=$(npm root -g) node tools/make-moon-1k.mjs
```

`tools/shot.mjs` は three を CDN から読めない環境でも動くよう、
`tools/vendor/three.module.js` があればそれで差し替える
（`npm pack three@0.160.0` で取れる。`.gitignore` 済み）。

性能計測は GPU の無い環境では絶対値が実機と比例しないので、
基準版との比だけを見るようにしてある。
